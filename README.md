
# SQL Data Analytics Project
A practical SQL-based data analytics project focused on exploring, analyzing, and reporting sales data using **SQL Server**.
This project demonstrates the use of SQL to explore data, calculate business metrics, analyze customer and product performance, identify trends, and build analytical reports.

---

## 🎯 Project Objectives
The main objectives of this project are to:
- 🔍 Explore and understand the database and its dimensions
- 📅 Analyze date ranges and time-based data
- 📊 Calculate important business measures and metrics
- 📈 Analyze sales magnitude, rankings, and changes over time
- 📉 Perform cumulative and performance analysis
- 👥 Segment customers based on different characteristics
- 🧩 Analyze relationships between different business components
- 📋 Create customer and product reports using SQL
  
---

## 🛠️ Tools & Technologies
- **SQL Server**
- **SQL Server Management Studio (SSMS)**
- **Git & GitHub**

## 📁 Project Structure
The project contains SQL scripts covering different areas of data exploration, analysis, and reporting.
| Script | Description |
|---|---|
| `00_init_database.sql` | Database initialization |
| `01_database_exploration.sql` | Database exploration |
| `02_dimensions_exploration.sql` | Exploration of dimension tables |
| `03_date_range_exploration.sql` | Analysis of date ranges |
| `04_measures_exploration.sql` | Exploration of key business measures |
| `05_magnitude_analysis.sql` | Magnitude analysis |
| `06_ranking_analysis.sql` | Ranking analysis |
| `07_change_over_time_analysis.sql` | Analysis of changes over time |
| `08_cumulative_analysis.sql` | Cumulative analysis |
| `09_performance_analysis.sql` | Performance analysis |
| `10_data_segmentation.sql` | Customer/data segmentation |
| `11_part_to_whole_analysis.sql` | Part-to-whole analysis |
| `12_report_customers.sql` | Customer reporting |
| `13_report_products.sql` | Product reporting |
